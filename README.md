# PIXEL / VALUE

Интерактивное социологическое исследование: **за что мы платим в игре?**

Почему игроки покупают косметические предметы (скины), даже если они не дают игрового преимущества.

- Автор: **Владислав Смирнов**, 11 класс
- Метод: собственный опрос, **n = 18**
- Теория: Self-Determination Theory (Deci & Ryan) + Extended Self (Belk)
- Формат: 23 кадра 16:9, режимы презентации / обзора / документации
- Год: 2025

## Сайт на GitHub Pages

1. Загрузите файл `index.html` в корень репозитория (можно через веб-интерфейс GitHub: Add file → Upload files).
2. Перейдите в **Settings → Pages**.
3. Source: **Deploy from a branch**.
4. Branch: `main`, folder: `/ (root)`.
5. Нажмите **Save**.

Через 1–2 минуты сайт будет доступен по адресу:

**https://smirka.github.io/pixel-value/**

## Структура

- `index.html` — презентация и её контроллер на vanilla JavaScript.
- `editorial.css` — оформление по выбранному редакционному макету и адаптивные стили.
- `assets/` — локальные изображения и иконки. Новые портрет и предметы созданы специально для иллюстрации исследования; это не скриншоты конкретной игры.

При переносе сайта копируйте `index.html`, `editorial.css` и папку `assets/` вместе. Для шрифтов и имеющейся библиотеки иконок используются внешние ресурсы; без сети доступны системные шрифты.

Проверки: `node tests/p4-presentation-smoke.js`, `node tests/navigation-regression.js`, `node tests/research-integrity.js`. Последняя сравнивает исследовательские кадры с исходным коммитом, поэтому требует Git-историю.

## Как пользоваться

- Стрелки ← → / Space — навигация по кадрам
- `G` — карта кадров
- `P` — режим докладчика
- `S` — документация проекта
- `E` — режим обзора (все кадры лентой)
- `F` — автоподгонка 16:9
- `Y` — направляющие
- `H` — справка

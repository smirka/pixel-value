# PIXEL / VALUE

Интерактивное социологическое исследование о ценности виртуальных предметов в видеоиграх.

- Автор исследования: Владислав Смирнов, 11 класс
- Метод: собственный описательный опрос, выборка `n = 18`
- Теоретическая основа: Self-Determination Theory и концепция «расширенного Я»
- Год проекта: 2026
- Формат: 23 кадра 16:9, режимы презентации и обзора, заметки докладчика

## Файлы

- `index.html` — содержание презентации и контроллер интерфейса.
- `styles.css` — базовые стили, сетка слайдов и состояния интерфейса.
- `editorial.css` — оформление иллюстраций, адаптивность и печатные стили.
- `assets/` — иллюстрации, видео, локальная библиотека Three.js и JavaScript-модули презентации.
- `tests/` — проверки структуры, данных, навигации и ресурсов.

Сборщик и пакетный менеджер не нужны. GitHub Pages публикует файлы как статический сайт. Для локального просмотра используйте HTTP-сервер: интерактивная 3D-сцена загружается как JavaScript-модуль. Three.js и медиафайлы входят в репозиторий. Веб-шрифты Inter и JetBrains Mono при наличии сети загружаются с jsDelivr; без сети используются системные шрифты.

## Публикация на GitHub Pages

1. Убедитесь, что `index.html`, `styles.css`, `editorial.css` и `assets/` находятся в корне репозитория.
2. Откройте **Settings → Pages**.
3. Выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Сохраните настройки и дождитесь публикации.

Для этого проекта адрес сайта: [smirka.github.io/pixel-value](https://smirka.github.io/pixel-value/).

## Проверки

Требуется Node.js. Запускайте команды из корня репозитория:

```sh
node --check assets/pv-showcase.js
node --check assets/pv-3d-scenes.js
node tests/p4-presentation-smoke.js
node tests/navigation-regression.js
node tests/research-integrity.js
node tests/art-composition.js
node tests/visual-assets.js
```

`research-integrity.js` сравнивает содержание исследования с базовым коммитом, поэтому для неё нужна Git-история.

## Управление

- `←` / `→`, `Space` — переход между кадрами
- `G` — карта кадров
- `P` — режим докладчика
- `S` — сведения о проекте
- `E` — режим обзора
- `F` — автоподгонка кадра 16:9
- `Y` — направляющие
- `H` — справка

Исследовательские данные и материалы цитируйте с указанием автора. Three.js распространяется по лицензии MIT; текст лицензии находится в `assets/three/LICENSE`.
